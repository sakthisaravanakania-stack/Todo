# ✨ Todo App

A simple, clean and responsive *Todo Management Application* built using *React.js* ⚛️

This project helps users create, manage, update and organize their daily tasks with an easy-to-use interface. 🚀

---

## 🌟 Features

✨ Add new todos  
📝 Edit existing todos  
🗑️ Delete todos  
✅ Mark todos as Completed  
⏳ Mark todos as Not Completed  
🔍 Filter todos by status  
📱 Fully responsive design  
🎨 Clean and modern user interface  
⚡ Fast and lightweight React application
